# ТЗ: подложки карты

**Проект:** GeoRoute («Майские прогулки»)  
**Область:** веб-интерфейс, карта Leaflet, выбор картографической подложки  
**Дата:** 2026-05-23  

---

## 1. Цель

Добавить рабочее переключение подложки карты.

Сейчас селект подложки уже есть в левой панели, но он не меняет карту. Нужно подключить его так, чтобы пользователь выбирал вид карты, а сама карта сразу меняла подложку.

---

## 2. Требуемые подложки

В селекте должны быть доступны:

- **OpenStreetMap** — подложка по умолчанию;
- **Yandex Maps**;
- **Google Maps**.

---

## 3. Поведение

| Сценарий | Действие пользователя | Результат |
|----------|-----------------------|-----------|
| Открытие приложения | Пользователь заходит в приложение | Загружается подложка **OpenStreetMap** |
| Смена подложки | Пользователь выбирает другой вариант в селекте слева | Меняется только вид карты |

При переключении подложки:

- текущий центр карты;
- текущий масштаб;
- маршруты;
- КП;
- вершины на линиях (основной трек и сегменты);
- сегменты маршрута;
- выбранный маршрут, текущая линия и режим редактирования

должны оставаться как были.

---

## 4. Критерии приемки

- [ ] При запуске приложения открывается OpenStreetMap.
- [ ] В левой панели можно выбрать OpenStreetMap, Yandex Maps или Google Maps.
- [ ] При выборе подложки меняется только вид карты.
- [ ] Маршруты, КП, вершины, сегменты маршрута, центр и масштаб карты не сбрасываются.
