# ТЗ: управление мышью на карте

**Проект:** GeoRoute («Майские прогулки»)  
**Дата:** 2026-05-22

---

## 1. Зачем это ТЗ

Пользователь должен **не путать** движение карты и работу с маршрутом. На всей карте — **одни и те же** правила для мыши.

| Действие | Что делает |
|----------|------------|
| **ЛКМ** | Выбор, редактирование (в режиме карандаша). Карту **не** двигает |
| **Колёсико зажато + движение** | Сдвиг карты |
| **Колёсико крутить** | Масштаб |
| **ПКМ** | Вне карты и на панелях — **ничего**. На карте в режиме редактирования — **удалить** вершину или КП |

---

## 2. Словарь (прочитать один раз)

### Из чего состоит маршрут

```text
Маршрут
├── КП — контрольные точки с номером (крупные значки)
├── Основной трек — главная линия маршрута
│   └── вершины (узлы) — маленькие кружки на линии
└── Сегменты — дополнительные линии только от КП до КП (их может быть 0, 1 или много)
    └── вершины (узлы)
```

### Главные слова

| Слово | Простыми словами |
|-------|------------------|
| **Полилиния** | Ломаная: много **вершин** и прямых **отрезков** между соседними вершинами |
| **Вершина** = **узел** | Одна точка на линии (маленький кружок). Не путать с КП и не путать с сегментом |
| **КП** | Особая точка маршрута с **номером**. Можно сделать из вершины. Это не вершина |
| **Основной трек** | Главная линия маршрута. **Не** называется сегментом |
| **Сегмент** | В этом ТЗ **всегда** значит: линия **строго от одного КП до другого КП**. Основной трек сегментом **не** называем |
| **Текущая линия** | То, что редактируем сейчас: основной трек **или** выбранный сегмент |
| **«Плюс»** | Между двумя вершинами — вставить вершину. Между двумя **КП** — создать **новый сегмент** |
| **Режим «редактировать»** | Включён карандашом внизу (после выбора маршрута слева). Это режим правки **всего выбранного маршрута**: основного трека, КП и сегментов |

**Три вещи не смешивать:** вершина (одна точка) · сегмент (целая линия КП→КП) · основной трек (главная линия, не сегмент).

**Цвет маршрута** (весь маршрут целиком) задаётся в панелях — как сейчас. **Подтверждение** сегмента и **отдельный цвет каждого сегмента** в списке справа (чтобы отличать сегменты друг от друга) — только у **сегментов** (линии КП→КП); основной трек сегментом не считается и не «подтверждается». **«Притянуть к тропе»:** если в списке справа **выбран сегмент** — притягивается он; если сегмент **не выбран** — притягивается **основной трек**.

## 3. Порядок работы пользователя

### 3.1. Выбор маршрута

1. **ЛКМ** по строке маршрута **слева** — маршрут выбран (строка подсвечена).
2. Сверху по центру: `Выбран маршрут "Название"`.
3. **Повторный ЛКМ** по той же строке — выбор снят, правая панель скрыта, карандаша нет.
4. Без выбранного маршрута редактировать **нельзя**.

### 3.2. Правая панель

| Ситуация | Что видно справа |
|----------|------------------|
| Маршрут не выбран | Панель **скрыта** |
| Маршрут выбран, карандаш **выключен** | Только **название** и **цвет** маршрута |
| Маршрут выбран, карандаш **включён** | КП, линии, сегменты, «Притянуть к тропе» и т.д. |

После снятия выбора маршрута правая панель не должна «залипать» на старых данных.

### 3.3. Режим редактирования (карандаш)

После выбора маршрута у карты есть два состояния:

1. **Просмотр** — карандаш выключен. Пользователь смотрит маршрут и не редактирует геометрию.
2. **Редактирование** — карандаш включён. Пользователь явно вошёл в режим правки выбранного маршрута.

Карандаш внизу показывается **только после выбора маршрута**. ЛКМ по карандашу переключает эти два состояния; сам маршрут при этом остаётся выбранным.

**Важно:** режим «редактировать» относится не только к рисованию основного трека. Это общий режим изменения геометрии выбранного маршрута: основного трека, вершин, КП, сегментов и линий выбранных сегментов. В этом режиме доступны добавление и перемещение вершин, создание КП, создание сегментов между КП, выбор сегмента и действия с ним.

### 3.3.1. Просмотр (карандаш выключен)

В этом состоянии карта не должна случайно менять маршрут.

| Что видно / доступно | Правило |
|----------------------|---------|
| КП | Видны |
| Основной трек | Виден |
| Подтверждённые сегменты | Видны сплошными линиями |
| Неподтверждённые сегменты | Скрыты |
| Вершины и «плюсы» | Скрыты |
| Клик по линии | Ничего не выбирает и не редактирует |
| ПКМ на карте | Ничего не делает |
| Правая панель | Только название и цвет маршрута |

**Исключение:** если у маршрута нет ни одного подтверждённого сегмента, то в режиме просмотра показываются все сегменты прерывистыми линиями. Это нужно, чтобы пользователь видел черновые сегменты до первого подтверждения.

### 3.3.2. Редактирование (карандаш включён)

В этом состоянии пользователь осознанно правит выбранный маршрут целиком: основной трек, КП и сегменты.

| Что видно / доступно | Правило |
|----------------------|---------|
| Верхняя надпись | `Выбран маршрут "Название" в режиме редактирования. ПКМ — удаление вершин и КП` |
| Вершины и «плюсы» | Видны на редактируемом маршруте; на остальных маршрутах не видны |
| Неподтверждённые сегменты | Видны |
| Правка линии и КП | Разрешена |
| Подтверждение сегментов | Разрешено |
| «Притянуть к тропе» | Разрешено по правилам раздела 8 |
| ПКМ по вершине или КП | Удаляет вершину или КП |
| ПКМ по пустой карте, линии или «плюсу» | Ничего не делает |

### 3.4. Esc

Отменяет текущее действие: незаконченную вершину, модалку номера КП (без сохранения), выходит из редактирования (маршрут остаётся выбранным). Если нечего отменять — ничего не ломает.

### 3.5. Нижняя панель

Оставить только **рабочие** кнопки. Убрать корзину, частичный мэтчинг, отменить/вернуть — если они ничего не делают. Удаление — **ПКМ** на карте в режиме редактирования.

## 4. ЛКМ на карте

### 4.1. Общее

- ЛКМ **не** двигает карту.
- Перетаскивание с зажатой ЛКМ по **вершине или КП** — двигает объект, не карту.

### 4.2. Пустое место на карте

Под «пустым местом» понимается клик по карте **не по линии, не по вершине, не по КП и не по «плюсу»**.

### 4.2.1. ЛКМ по пустому месту

| Условие | Что происходит |
|---------|----------------|
| Выбран маршрут, включён карандаш, выбрана текущая линия этого маршрута | В конец **текущей линии выбранного маршрута** добавляется новая вершина |
| Маршрут не выбран | Ничего |
| Карандаш выключен | Ничего |
| Текущая линия не выбрана | Ничего |

Новая вершина **никогда** не добавляется в другой маршрут и не добавляется в линию, которая не выбрана как текущая.

### 4.2.2. Движение мыши по пустому месту

| Условие | Что видно |
|---------|-----------|
| Выбран маршрут, включён карандаш, в текущей линии уже есть хотя бы одна вершина | Показывается предпросмотр следующего отрезка: временная линия от последней вершины текущей линии до курсора |
| Любое другое состояние | Ничего |

В этом ТЗ **«резиновая линия»** означает только одно: **предпросмотр следующего отрезка**, который появится, если пользователь сейчас кликнет ЛКМ по пустому месту.

Правила:

- линия начинается в **последней вершине текущей линии**;
- второй конец линии всегда находится **в текущей позиции курсора**;
- она **двигается вместе с курсором**;
- она **не добавляет вершину сама**;
- она **не сохраняется**;
- она становится обычным отрезком маршрута **только после ЛКМ**, когда в месте клика создаётся новая вершина.

### 4.3. Вершина (маленький кружок)

| Условие | Результат |
|---------|-----------|
| Карандаш включён, **клик** | Модалка: ввести **номер КП** (см. ниже) |
| Карандаш включён, **перетаскивание** | Сдвинуть вершину, линия перестраивается |
| Карандаш выключен | Ничего |

**Модалка номера КП**

- Только **цифры**, номер **уникален** в этом маршруте.
- Допустимо: `1` … `2147483647`. Запрещено: `0`, минус, дроби, `01` / `001`, пусто.
- Сохранить — вершина становится КП с этим номером.
- Esc / отмена — КП не создаётся.
- Пока модалка открыта — клики по карте не добавляют вершины.

### 4.4. «Плюс»

| Где «плюс» | Результат (карандаш включён) |
|------------|------------------------------|
| Между двумя **вершинами** | Вставить вершину между ними (перетаскивание «плюса» — то же) |
| Между двумя **КП** (в т.ч. на основном треке) | Создать **новый сегмент** между этими КП |

Если нужно вставить точку между обычными вершинами, пользователь нажимает именно **«плюс»** между ними.

### 4.5. КП (крупный значок)

| Условие | Результат |
|---------|-----------|
| Карандаш включён, **повторный клик** по КП | КП снова становится **вершиной** |
| Карандаш включён, **перетаскивание** | Перенести КП |
| Карандаш выключен | Ничего |

### 4.6. Сегмент (линия КП→КП)

Здесь **сегмент** — только линия **от одного КП до другого КП**. Основной трек не считается сегментом.

### 4.6.1. Что можно считать сегментом

| Условие | Это сегмент? |
|---------|--------------|
| Линия начинается в КП и заканчивается в КП | Да |
| Линия между обычными вершинами | Нет |
| Часть основного трека без отдельного сегмента | Нет |
| Основной трек целиком | Нет |

### 4.6.2. Клик по сегменту

Этот раздел только про клик по уже созданному **сегменту КП→КП**.

| Условие | Результат |
|---------|-----------|
| Выбран маршрут, карандаш включён, клик по сегменту **этого маршрута** | Сегмент становится выбранным: линия визуально выделяется, справа выделяется его строка |
| Выбран маршрут, карандаш включён, клик по сегменту **другого маршрута** | Ничего; редактируется только выбранный маршрут |
| Карандаш выключен | Ничего; сегмент не выбирается, потому что вне редактирования список сегментов справа скрыт и выбор сегмента недоступен |

Выбор сегмента нужен только для действий с ним: подтвердить сегмент, удалить сегмент, «Притянуть к тропе» только выбранный сегмент.

### 4.7. Панели (не карта)

| Место | ЛКМ |
|-------|-----|
| Строка маршрута слева | Выбрать / снять выбор маршрута |
| Чекбокс слева | Показать / скрыть линии на карте |
| Корзина слева | Удалить маршрут |
| Строка линии справа | Выбрать **текущую линию** (трек или сегмент) |
| Глаз справа | Видимость сегмента на карте |
| Кнопка **«Подтвердить»** справа | Принять выбранный сегмент как часть основного трека |
| Удаление справа | Удалить выбранный сегмент |
| «Старт» / «Конец» | **Убрать** — границы сегмента только через КП и «плюс» |
| KML слева | **Убрать**, пока не реализовано |

## 5. Средняя кнопка (колёсико)

| Действие | Результат |
|----------|-----------|
| Зажать + двигать | Сдвиг карты |
| Клик без движения | Ничего |
| Прокрутка | Масштаб |

ЛКМ с перетаскиванием по пустой карте карту **не** сдвигает.

## 6. ПКМ

ПКМ нужна только для удаления объектов на карте в режиме редактирования.

ПКМ **не включает** режим редактирования. Режим редактирования включается только кнопкой-карандашом.

Меню браузера по ПКМ **нигде** не показывается.

| Где нажали ПКМ | Режим просмотра (карандаш выключен) | Режим редактирования (карандаш включён) |
|----------------|------------------------------------|------------------------------------------|
| Панели, поля, кнопки | Ничего | Ничего |
| Пустая карта, линия, «плюс» | Ничего | Ничего |
| Вершина | Ничего | Удалить вершину |
| КП / Match | Ничего | Удалить КП / Match |

## 7. Сегменты: создание и подтверждение

**Сегмент** = линия **от КП до КП** (внутри — вершины). Основной трек этому не подчиняется.

Создание и подтверждение сегментов доступны **только в режиме редактирования**: маршрут выбран, карандаш включён. В режиме просмотра сегменты можно только смотреть; создать или подтвердить сегмент нельзя.

**Создать сегмент:** в режиме редактирования на основном треке между двумя КП нажать **«плюс»** → появится новый сегмент между этими КП.

**Подтвердить сегмент** — принять выбранный сегмент как часть основного трека. После подтверждения участок основного трека между теми же КП заменяется линией выбранного сегмента.

1. ЛКМ по сегменту на карте — он выбран.
2. Справа подсвечена строка сегмента.
3. Кнопка **«Подтвердить»** под списком сегментов.
4. Подтверждённый — **сплошная** линия, в списке **зелёный**, строка **вверху**.
5. Неподтверждённый — **прерывистая** линия.

У **маршрута** — общий **цвет маршрута**. У **каждого сегмента** дополнительно свой цвет линии (при создании — случайный, не совпадающий с другими сегментами этого маршрута).

---

## 8. «Притянуть к тропе»

Кнопка работает только в режиме редактирования: **маршрут выбран** и **карандаш включён**. В остальных случаях кнопка **неактивна**.

Что именно притягиваем:

| Текущее выделение | Что меняется после нажатия |
|-------------------|----------------------------|
| Выделен **сегмент** | Только этот сегмент. Не важно, подтверждён он или нет |
| Сегмент не выделен, выделен основной трек или ничего не выделено | Только **основной трек** выбранного маршрута. Сегменты не меняются |

Правило выбора цели одно: если выделен сегмент — притягиваем его; во всех остальных случаях притягиваем основной трек.

## 9. Что доработать в коде

Этот раздел не вводит новых правил. Он раскладывает по задачам то, что описано выше в разделах 1-8.

### 9.1. Общие состояния карты

В коде должно быть явно разделено несколько состояний:

| Состояние | Что означает |
|-----------|--------------|
| Маршрут не выбран | Нельзя редактировать, правая панель скрыта, карандаш скрыт |
| Маршрут выбран, карандаш выключен | Режим просмотра: можно смотреть маршрут, но нельзя менять геометрию |
| Маршрут выбран, карандаш включён | Режим редактирования: можно менять основной трек, КП и сегменты выбранного маршрута |
| Выбран сегмент | Дополнительное состояние внутри редактирования; действия вроде «Подтвердить», удалить сегмент и «Притянуть к тропе» относятся к нему |
| Выбрана текущая линия | Линия, в которую можно добавлять вершины: основной трек или выбранный сегмент |

Нужно убрать поведение, при котором отдельные клики на карте сами переводят приложение в редактирование. Редактирование включается только карандашом после выбора маршрута.

### 9.2. Выбор маршрута слева

Нужно доработать выбор маршрута так, чтобы он был единственной точкой входа в работу с маршрутом:

| Что есть сейчас / проблема | Что нужно сделать |
|----------------------------|-------------------|
| После снятия выбора могут оставаться элементы старого маршрута | При снятии выбора очищать выбранный маршрут, выбранный сегмент, текущую линию, временную линию и состояние редактирования |
| Повторный клик по маршруту может не снимать выбор | Повторный ЛКМ по уже выбранному маршруту должен полностью снимать выбор |
| Карандаш может быть доступен без выбранного маршрута | Карандаш показывать только когда выбран маршрут |
| Правая панель может показываться без маршрута | Правая панель должна быть полностью скрыта, если маршрут не выбран |
| Состояние редактирования может сохраняться после смены маршрута | При выборе другого маршрута сбрасывать редактирование, выбранный сегмент и текущую линию |

После выбора маршрута слева маршрут должен оставаться выбранным и в просмотре, и в редактировании. Карандаш меняет только режим, но не сам выбранный маршрут.

### 9.3. Верхний индикатор состояния

Нужно добавить или доработать верхний текстовый индикатор:

| Условие | Текст |
|---------|-------|
| Маршрут не выбран | Ничего не показывать или показывать нейтральное состояние без названия маршрута |
| Маршрут выбран, карандаш выключен | `Выбран маршрут "Название"` |
| Маршрут выбран, карандаш включён | `Выбран маршрут "Название" в режиме редактирования. ПКМ — удаление вершин и КП` |

Индикатор должен обновляться сразу после выбора маршрута, снятия выбора и переключения карандаша.

### 9.4. Правая панель

Правая панель должна зависеть от выбора маршрута и режима:

| Условие | Что показывать |
|---------|----------------|
| Маршрут не выбран | Панель скрыта полностью |
| Маршрут выбран, карандаш выключен | Только название маршрута и цвет маршрута |
| Маршрут выбран, карандаш включён | Полный набор редактирования: КП, линии, сегменты, действия с сегментами, «Притянуть к тропе» |

Нужно убрать ситуацию, когда пользователь видит элементы редактирования без включённого карандаша.

Отдельно нужно проверить, что при снятии выбора маршрута справа не остаются:

- старое название маршрута;
- старый цвет;
- список старых КП;
- список старых линий;
- выбранный ранее сегмент;
- кнопки действий для старого маршрута.

### 9.5. Нижняя панель

Нужно оставить только рабочие кнопки, которые соответствуют этому ТЗ.

Убрать из нижней панели:

- корзину;
- частичный мэтчинг, если он не работает;
- отменить / вернуть, если они не работают;
- любые кнопки, которые визуально доступны, но не выполняют понятное действие.

Удаление объектов маршрута не должно быть завязано на нижнюю корзину. По этому ТЗ удаление вершины или КП выполняется ПКМ на карте в режиме редактирования.

### 9.6. ЛКМ и движение карты

Нужно развести редактирование маршрута и перемещение карты:

| Действие | Что должно быть |
|----------|-----------------|
| ЛКМ по пустой карте без выбранного маршрута | Ничего |
| ЛКМ по пустой карте при выключенном карандаше | Ничего |
| ЛКМ по пустой карте в редактировании, но без текущей линии | Ничего |
| ЛКМ по пустой карте в редактировании и с текущей линией | Добавить вершину в конец текущей линии |
| Зажать ЛКМ на пустой карте и двигать | Карту не двигать |
| Зажать ЛКМ на вершине или КП и двигать | Перемещать вершину или КП |

Если в текущей линии есть хотя бы одна вершина, при движении мыши по пустому месту в режиме редактирования нужно показывать временную линию от последней вершины до курсора. Эта линия не должна сохраняться без клика.

### 9.7. Средняя кнопка мыши

Нужно перенести перемещение карты на среднюю кнопку мыши:

| Действие | Что должно быть |
|----------|-----------------|
| Зажать колёсико и двигать мышь | Двигать карту |
| Просто кликнуть колёсиком | Ничего не менять |
| Крутить колёсико | Масштабировать карту |

Это правило должно работать одинаково в просмотре и в редактировании.

### 9.8. ПКМ

Нужно исправить ПКМ так, чтобы она не включала карандаш и не запускала сторонние действия.

| Где нажали ПКМ | Что нужно сделать |
|----------------|-------------------|
| Панели, поля, кнопки | Ничего |
| Пустая карта | Ничего |
| Линия | Ничего |
| «Плюс» | Ничего |
| Вершина в режиме просмотра | Ничего |
| КП в режиме просмотра | Ничего |
| Вершина в режиме редактирования | Удалить вершину |
| КП / Match в режиме редактирования | Удалить КП / Match |

Контекстное меню браузера по ПКМ не должно появляться.

После удаления вершины или КП нужно обновить линию, список КП, список сегментов и видимость «плюсов» так, чтобы не оставалось битых ссылок на удалённые точки.

### 9.9. Вершины

Нужно привести вершины к правилам из раздела 4:

| Действие | Что нужно сделать |
|----------|-------------------|
| Клик по вершине в редактировании | Открыть модалку номера КП |
| Перетаскивание вершины в редактировании | Переместить вершину и перестроить линию |
| Клик по вершине в просмотре | Ничего |
| ПКМ по вершине в редактировании | Удалить вершину |
| ПКМ по вершине в просмотре | Ничего |

Вершина не должна автоматически становиться КП без модалки.

### 9.10. Модалка номера КП

Нужно добавить модалку создания КП из вершины.

Модалка открывается только при клике по вершине в режиме редактирования.

Правила ввода:

| Значение | Результат |
|----------|-----------|
| `1` | Можно сохранить, если номер не занят |
| `2147483647` | Можно сохранить, если номер не занят |
| `0` | Нельзя сохранить |
| `-1` | Нельзя сохранить |
| `1.5` | Нельзя сохранить |
| `01` / `001` | Нельзя сохранить |
| Пустая строка | Нельзя сохранить |
| Номер, который уже есть у КП этого маршрута | Нельзя сохранить |

Поведение модалки:

- кнопка сохранения доступна только при валидном и уникальном номере;
- при сохранении выбранная вершина становится КП;
- Esc закрывает модалку без создания КП;
- отмена закрывает модалку без создания КП;
- пока модалка открыта, клики по карте не добавляют вершины и не создают другие КП;
- после успешного создания КП обновляются линия, список КП, «плюсы» и возможные точки создания сегментов.

### 9.11. КП

Нужно доработать КП как отдельный тип точки, не смешивая его с обычной вершиной.

| Действие | Что нужно сделать |
|----------|-------------------|
| Повторный клик по КП в редактировании | Превратить КП обратно в обычную вершину |
| Перетаскивание КП в редактировании | Переместить КП и перестроить связанные линии |
| ПКМ по КП в редактировании | Удалить КП / Match |
| Любое действие с КП в просмотре | Ничего не менять |

После превращения КП обратно в вершину нужно проверить сегменты, которые начинались или заканчивались в этом КП: сегмент не может существовать без двух КП на концах.

### 9.12. «Плюсы»

Нужно разделить два разных поведения «плюса»:

| Где находится «плюс» | Что нужно сделать |
|----------------------|-------------------|
| Между двумя обычными вершинами | Вставить новую вершину между ними |
| Между двумя КП | Создать новый сегмент КП→КП |

«Плюсы» должны быть видны только в режиме редактирования выбранного маршрута. На других маршрутах они не должны появляться.

При создании нового сегмента между КП:

- сегмент должен принадлежать выбранному маршруту;
- начало и конец сегмента должны быть именно КП;
- сегмент должен получить свой цвет;
- сегмент должен быть неподтверждённым;
- сегмент должен отображаться пунктиром;
- сегмент должен появиться в списке сегментов справа.

### 9.13. Сегменты

Нужно привести модель и UI к одному правилу: сегментом считается только линия КП→КП.

Не считать сегментом:

- основной трек целиком;
- часть основного трека без отдельной линии сегмента;
- линию между обычными вершинами;
- временную линию предпросмотра.

Для сегментов нужно реализовать или проверить:

| Область | Что нужно сделать |
|---------|-------------------|
| Создание | Только через «плюс» между двумя КП в режиме редактирования |
| Выбор | ЛКМ по сегменту выбранного маршрута в режиме редактирования |
| Выделение | Выделять линию на карте и строку справа |
| Цвет | У каждого сегмента свой цвет, при создании случайный и не совпадает с другими сегментами маршрута |
| Неподтверждённый вид | Пунктир |
| Подтверждённый вид | Сплошная линия |
| Список справа | Подтверждённые сверху, зелёные; неподтверждённые ниже |
| Доступность действий | Подтвердить, удалить и выбрать сегмент можно только в редактировании |

Нужно убрать элементы «Старт» и «Конец». Границы сегмента задаются только КП и созданием через «плюс» между КП.

### 9.14. Подтверждение сегмента

Подтверждение доступно только когда:

- выбран маршрут;
- включён карандаш;
- выбран сегмент этого маршрута.

После подтверждения:

- участок основного трека между теми же КП заменяется линией выбранного сегмента;
- сегмент становится подтверждённым;
- линия сегмента отображается сплошной;
- строка сегмента в списке становится зелёной;
- строка подтверждённого сегмента поднимается выше неподтверждённых;
- остальные сегменты не подтверждаются автоматически;
- основной трек не становится «сегментом» и не попадает в правила подтверждения сегментов.

### 9.15. Видимость объектов

Нужно привести видимость объектов к двум режимам.

В режиме редактирования:

- видны вершины выбранного маршрута;
- видны «плюсы» выбранного маршрута;
- видны КП выбранного маршрута;
- виден основной трек;
- видны все сегменты выбранного маршрута;
- неподтверждённые сегменты видны пунктиром;
- подтверждённые сегменты видны сплошной линией.

В режиме просмотра:

- видны КП;
- виден основной трек;
- видны подтверждённые сегменты;
- неподтверждённые сегменты скрыты;
- вершины скрыты;
- «плюсы» скрыты;
- если у маршрута нет ни одного подтверждённого сегмента, показываются все сегменты пунктиром.

Видимость через «глаз» справа должна применяться к сегментам, но не должна ломать общие правила режима просмотра и редактирования.

### 9.16. «Притянуть к тропе»

Нужно исправить доступность и цель кнопки:

| Условие | Что должно быть |
|---------|-----------------|
| Маршрут не выбран | Кнопка недоступна или не показана |
| Маршрут выбран, карандаш выключен | Кнопка недоступна |
| Маршрут выбран, карандаш включён, сегмент не выбран | Притягивается только основной трек |
| Маршрут выбран, карандаш включён, выбран сегмент | Притягивается только выбранный сегмент |

Кнопка не должна менять все сегменты сразу. Подтверждённость сегмента не влияет на возможность притянуть выбранный сегмент.

### 9.17. Esc

Нужно реализовать Esc по сценарию из раздела 3.4.

Esc должен:

- закрывать модалку номера КП без сохранения;
- отменять незаконченное действие добавления вершины;
- убирать временную линию предпросмотра;
- выходить из режима редактирования, если больше нечего отменять;
- оставлять маршрут выбранным после выхода из редактирования.

Esc не должен:

- удалять маршрут;
- удалять вершину;
- удалять КП;
- сбрасывать выбранный маршрут, если пользователь просто вышел из редактирования;
- ломать текущий список сегментов.

### 9.18. Файлы, которые нужно проверить

Основные файлы:

- `Map.tsx` — состояние карты, выбранный маршрут, режим редактирования, обработчики карты, временная линия, верхний индикатор.
- `MapHandlerComponent` — обработка ЛКМ, ПКМ, движения мыши, средней кнопки, Esc.
- `Markers.tsx` — отображение КП / Match, клики, перетаскивание, ПКМ, превращение КП обратно в вершину.
- `NodeMarkers.tsx` — отображение вершин, «плюсов», вставка вершин, создание КП, создание сегментов между КП.
- `MiddleButtonPan.tsx` — перемещение карты через зажатое колёсико.
- `BottomMenu.tsx` — скрытие нерабочих кнопок, показ карандаша только при выбранном маршруте.
- `LeftMenu.tsx` — выбор / снятие выбора маршрута, чекбоксы видимости, удаление маршрута слева.
- `main.tsx` — подключение обработчиков, если глобальные события мыши или клавиатуры находятся там.
- `README_user.md` — обновить пользовательское описание после доработки поведения.

Дополнительно нужно проверить все места, где используются слова `segment`, `line`, `node`, `match`, `checkpoint`, чтобы основной трек не обрабатывался как сегмент.

### Видимость
- [ ] В режиме редактирования видны КП выбранного маршрута.
- [ ] В режиме редактирования виден основной трек выбранного маршрута.
- [ ] В режиме редактирования видны вершины выбранного маршрута.
- [ ] В режиме редактирования видны «плюсы» выбранного маршрута.
- [ ] В режиме редактирования видны все сегменты выбранного маршрута.
- [ ] В режиме редактирования подтверждённые сегменты отображаются сплошной линией.
- [ ] В режиме редактирования неподтверждённые сегменты отображаются пунктиром.
- [ ] В режиме просмотра видны КП.
- [ ] В режиме просмотра виден основной трек.
- [ ] В режиме просмотра подтверждённые сегменты видны сплошной линией.
- [ ] В режиме просмотра неподтверждённые сегменты скрыты, если есть хотя бы один подтверждённый сегмент.
- [ ] В режиме просмотра, если подтверждённых сегментов нет, все сегменты видны пунктиром.
- [ ] В режиме просмотра вершины скрыты.
- [ ] В режиме просмотра «плюсы» скрыты.
- [ ] Переключение карандаша сразу обновляет видимость вершин, «плюсов» и сегментов.
- [ ] Снятие выбора маршрута скрывает редактируемые элементы выбранного маршрута.
- [ ] Видимость через «глаз» справа не превращает основной трек в сегмент.

### Притянуть к тропе
- [ ] Без выбранного маршрута кнопка «Притянуть к тропе» недоступна или не показана.
- [ ] При выбранном маршруте, но выключенном карандаше кнопка недоступна.
- [ ] При выбранном маршруте и включённом карандаше кнопка доступна.
- [ ] Если сегмент не выбран, кнопка притягивает только основной трек.
- [ ] Если выбран основной трек, но сегмент не выбран, кнопка притягивает только основной трек.
- [ ] Если выбран сегмент, кнопка притягивает только этот сегмент.
- [ ] При выбранном сегменте основной трек не меняется.
- [ ] При отсутствии выбранного сегмента сегменты не меняются.
- [ ] Подтверждённый выбранный сегмент можно притянуть.
- [ ] Неподтверждённый выбранный сегмент можно притянуть.
