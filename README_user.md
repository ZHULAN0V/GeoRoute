# Инструкция пользователя: веб-интерфейс «Майские прогулки»

Документ описывает экран приложения в браузере: расположение панелей, кнопки, поля ввода и действия на карте. Заголовок вкладки в браузере: **«Майские прогулки»**.

---

## Общий вид экрана

Интерфейс состоит из четырёх частей:

1. **Карта** — на весь экран по центру (под панелями), фоновая подложка **OpenStreetMap**.
2. **Левая панель** («Меню маршрутов») — вверху слева, полупрозрачная с прокруткой.
3. **Правая панель** («Меню маршрута») — вверху справа.
4. **Нижняя панель инструментов** — по центру внизу экрана, ряд иконок-кнопок.

Стандартное контекстное меню браузера по правой кнопке мыши на странице отключено; на карте при этом обрабатывается **собственное** действие (см. раздел про карту).

Кнопки **+** и **−** масштаба Leaflet на карте скрыты: масштаб меняйте **колёсиком мыши** (или жестами на тачпаде/сенсорном экране). Карту можно **перетаскивать**, удерживая левую кнопку мыши.

---

## Левая панель: «Меню маршрутов»

### Выбор подложки карты (выпадающий список)

Под заголовком «Меню маршрутов» расположен список с подписями **Open street maps**, **Yandex maps**, **Google maps**. В текущей версии приложения фактически используется слой **OpenStreetMap**; переключение подложки через этот список может не менять карту.

### Список маршрутов

Каждая строка маршрута показывает:

- **Название** маршрута;
- **Длину** в километрах (оценка по точкам основного варианта);
- **Цвет** — прямоугольник и текстовый код цвета;
- **Кнопка «Удалить»** (иконка корзины) — удаляет маршрут из списка и связанные данные на сервере (если маршрут был сохранён);
- **Кнопка «Выбрать»** (чекбокс) — включает или выключает отображение линий этого маршрута на карте среди **отмеченных галочкой** маршрутов.

**Клик по строке маршрута** (по карточке, не по кнопкам) делает этот маршрут **текущим** для правой панели и для рисования на карте. При выборе маршрута подставляется его первый вариант для редактирования.

### Кнопка «Добавить маршрут»

Создаёт новый пустой маршрут с временным именем и цветом по умолчанию и одним вариантом «Основной».

### Экспорт и импорт

- **GPX** (кнопка с иконкой загрузки) — сохраняет на компьютер файл **`paths.gpx`** с линией **текущего выбранного варианта** активного маршрута (последовательность точек).
- **KML** — кнопка отображается, отдельного действия при нажатии в интерфейсе не задано.
- **«Загрузить GPX»** — открывает выбор файла с расширением **.gpx**; после выбора маршрут добавляется в список из трека файла. При ошибке формата под кнопкой показывается сообщение об ошибке; при успехе может отображаться имя файла.

При открытии приложения список имён файлов маршрутов запрашивается с сервера; при успешном ответе сохранённые маршруты подгружаются в интерфейс.

## Правая панель: «Меню маршрута»

Панель активна, когда в левом списке выбран маршрут.

### Название и цвет маршрута

- Поле **«Название маршрута»** — текстовое; изменения применяются с небольшой задержкой после ввода.
- **Поле выбора цвета** (цветной квадрат) — цвет маршрута в целом; также синхронизируется с задержкой.

### Блок «Выбор сегмента маршрута»

Используется для работы с **контрольными точками (маркерами)** на карте:

- **«Старт»** — выпадающий список: пункт **«Нет»** или один из маркеров текущего маршрута.
- **«Конец»** — аналогично.
- **«Название Маркера»** — редактирует название маркера, выбранного в поле **«Старт»** (после ввода имя обновляется с задержкой).

При смене текущего маршрута выбор «Старт»/«Конец» сбрасывается.

Список **«Варианты маршрута»** ниже может фильтроваться: показываются варианты, согласованные с выбранными маркерами старта/финиша (если они заданы).

### Варианты маршрута

Каждая карточка варианта показывает имя, длину в км, цвет и кнопки:

- **Клик по карточке** — сделать этот вариант **текущим** для редактирования на карте.
- **«Слияние»** (иконка слияния) — только у **неосновных** вариантов: объединить вариант с основным маршрутом.
- **«Удалить»** — только у неосновных вариантов: удалить вариант.
- **«Глаз»** / **«Глаз перечёркнут»** — включить или выключить отображение линии этого варианта на карте (в комбинации с правилами показа других линий).

### Название и цвет варианта

Под списком вариантов:

- **«Название варианта»** — имя текущего выбранного варианта.
- **Цвет варианта** — отдельное поле цвета для линии этого варианта.

### Кнопка «Добавить вариант»

Создаёт новый вариант у текущего маршрута (копия имени/цвета по умолчанию от маршрута), с пустой линией до добавления точек.

### Кнопка «Притянуть к тропе»

Отправляет на сервер текущую линию (в виде GPX), получает **сопоставленный с дорожной/тропной сетью** вариант трека и подставляет точки в маршрут. Если задан сегмент по маркерам «Старт»–«Конец», обрабатывается участок между ними, после чего соответствующие служебные маркеры могут быть сняты. Во время запроса кнопка показывает состояние загрузки.

### Кнопка «Сохранить»

Сохраняет **текущий маршрут целиком** на сервер в формате GPX (под именем идентификатора маршрута). Во время сохрузки отображается индикатор загрузки.

## Нижняя панель инструментов

Слева направо (при наведении показываются подсказки):

| Подсказка | Назначение в интерфейсе |
|-----------|-------------------------|
| **редактировать** | Режим **рисования/добавления точек** левым кликом по карте; на карте рисуется «резиновая» линия от последней точки к курсору. Повторное нажатие снимает режим. |
| **удалить** | Переключает подсветку кнопки; **отдельного режима удаления точек кликом по карте** в логике карты не используется. Удаление точек — через маркеры на карте (см. ниже). |
| **частичный мэтчинг** | Режим, при котором **клик по точке линии** на карте создаёт маркер для **частичного сопоставления** (в названии будет префикс «Match»). В обычном режиме редактирования такой клик создаёт обычный контрольный маркер («КП …»). |
| **отменить** | Переключает подсветку кнопки; **история действий «Отменить» в коде карты не подключена**. |
| **вернуть отмененное** | Аналогично, подсветка без отдельной логики «Повторить» на карте. |

То есть для практической работы с линией важны в первую очередь режимы **«редактировать»** и **«частичный мэтчинг»**.

## Карта: действия мышью

Все описанное относится к **текущему маршруту** и **текущему варианту**, выбранным в боковых панелях.

### Левый клик по карте

- В режиме **«редактировать»** — добавляет **новую вершину** полилинии в конец текущей цепочки точек.
- В других режимах добавление точек таким кликом **не выполняется**.

### Правый клик по карте

Принудительно включает режим **«редактировать»** (как нижняя кнопка с карандашом).

### Точки линии (круглые маркеры на треке)

- **Перетаскивание** — сдвигает вершину; линия перестраивается.
- **Левый клик** — создаёт **контрольный маркер** в этой точке: в режиме «частичный мэтчинг» — маркер для сопоставления сегмента (**Match**), иначе — контрольная точка маршрута (**КП**). Маркер появляется на карте с подписью (имя над значком).
- **Правый клик по точке** — **удаляет** эту вершину с линии.

### Промежуточные маркеры («плюс» между двумя вершинами)

Расположены посередине между соседними точками. **Клик** или **окончание перетаскивания** вставляет новую вершину **между** двумя соседними точками (уточняет форму линии).

### Маркеры контрольных точек (значок похож на логотип карт)

Отображают созданные **КП / Match**-маркеры с **постоянной подписью** (имя или «Маркер», если имя пустое).

- **Перетаскивание** — переносит маркер на карте.
- **Левый клик**:
  - в режиме **«редактировать»** — добавляет вершину линии в позицию маркера и привязывает сегмент к маркерам **старт/финиш** варианта (первая точка цепочки задаёт старт варианта, следующие — финиш);
  - в **других** режимах (включая пустой режим после повторного нажатия на «редактировать») — выбирает маркер как **«Старт»** в блоке «Выбор сегмента маршрута» на правой панели (для построения сегмента и фильтра вариантов).
- **Правый клик** — **удаляет** маркер.

### Отображение линий

- **Текущий вариант** — яркая линия своего цвета; при режиме «редактировать» дополнительно линия от последней точки к курсору.
- **Другие линии** — показываются у маршрутов, отмеченных чекбоксом в левой панели: видны **основные** варианты и **дополнительные варианты текущего маршрута**, для которых включена видимость («глаз»), кроме самого редактируемого варианта (он не дублируется вторым слоем).

## Краткая последовательность для нового маршрута

1. **«Добавить маршрут»** слева → при необходимости переименовать и выбрать цвет справа.
2. Включить **«редактировать»** внизу.
3. Кликами по карте обвести трек; при необходимости двигать точки, вставлять точки через «плюсы», удалять лишнее правым кликом по точке.
4. По желанию поставить **КП** кликом по точке линии; для сегментного сопоставления использовать **«частичный мэтчинг»** и выбрать **Старт/Конец** в правой панели.
5. **«Притянуть к тропе»** — выровнять трек по сети дорог/троп.
6. **«Сохранить»** — записать на сервер; **«GPX»** слева — выгрузить файл с текущего варианта на диск.
